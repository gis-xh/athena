# 桌面应用开发

> 用 Web 技术与原生技术构建跨平台桌面应用：Electron、Rust + Tauri，以及 Python 的 PyQt 方案。

## 适合谁 / 前置要求

- 已掌握一门后端或前端语言；
- Electron 需要 Node.js 基础，Tauri 需要 Rust 基础（见[Rust 环境配置](rust-setup.md)）。

## 学习路径

1. [Rust 环境配置](rust-setup.md)（入门）：Windows 下 Rust 工具链安装；
2. [Electron](electron.md)（进阶）：基于 Chromium + Node.js 的桌面应用；
3. PyQt、C++ Qt、Rust + Tauri 文档规划中，暂未开放。

## 能力目标

学完后你能搭建一个最小可运行的桌面应用，并理解 Electron 与 Tauri 的资源占用和打包差异。

## 配套练习 / 项目

- 用 Electron 封装一个本地 Markdown 阅读器；
- 用 Tauri 创建窗口并调用一次 Rust 函数，比较两者的打包体积。
