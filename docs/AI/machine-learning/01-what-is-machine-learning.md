# 什么是机器学习

> 本页是吴恩达《Machine Learning》第一周内容的结构化笔记，帮助你建立机器学习的基本概念框架：定义、监督学习与非监督学习的区别。

## 学习目标

- 能用一句话向别人解释“机器学习是什么”；
- 能区分监督学习与无监督学习，并举出各自的应用；
- 理解“特征、标签、训练、预测”这四个基础词。

## 前置要求

- 无需编程基础，本页只讲概念；
- 建议配合 Python 环境一起学习（参考[环境配置](../../setup/dev/python-uv-setup.md)）。

## 1 机器学习的定义

机器学习是**让计算机从数据中自动学习规律，而不是由人显式编写规则**的科学。

例如：我们不需要手写“如何识别垃圾邮件”的规则，而是给程序大量“正常邮件/垃圾邮件”的样本，让它自己找到规律。

## 2 四个基础词

| 词 | 含义 | 例子 |
| --- | --- | --- |
| 特征（feature） | 描述样本的属性 | 邮件中的关键词、图片像素 |
| 标签（label） | 样本对应的答案 | 是否垃圾邮件 |
| 训练（training） | 用带答案的数据学习参数 | 让模型拟合历史邮件 |
| 预测（prediction） | 对未见过的数据输出结果 | 判断新邮件 |

## 3 监督学习

监督学习使用**带标签**的数据：每个样本都有正确答案。

### 3.1 回归（预测连续值）

输出是连续数字，例如：

- 根据房屋面积、位置预测房价；
- 根据历史数据预测明天温度。

### 3.2 分类（预测离散类别）

输出是类别，例如：

- 判断邮件是垃圾邮件还是正常邮件；
- 判断图片里是猫还是狗；
- 判断肿瘤是否为恶性。

## 4 无监督学习

无监督学习使用**不带标签**的数据，让模型自己发现结构。

### 4.1 聚类（clustering）

把相似的数据自动分到一组，例如：

- 新闻网站把相似文章自动归类；
- 电商把用户分成不同购买偏好的群体。

### 4.2 其他无监督任务

- 降维：把高维数据压缩到可视化的两三维；
- 异常检测：发现与大多数数据不同的点（如信用卡盗刷）；
- 关联规则：发现“买了 A 的人常买 B”。

## 5 两种学习的快速对比

| 维度 | 监督学习 | 无监督学习 |
| --- | --- | --- |
| 数据 | 有标签 | 无标签 |
| 目标 | 预测答案 | 发现结构 |
| 典型任务 | 回归、分类 | 聚类、降维、异常检测 |
| 例子 | 房价预测、垃圾邮件识别 | 用户分群、新闻聚类 |

## 6 机器学习在哪里被使用

- 搜索引擎排序网页；
- 相册自动识别并标记好友；
- 视频网站推荐你可能喜欢的电影；
- 手机语音转文字、语音助手；
- 邮箱自动过滤垃圾邮件；
- 工厂用计算机视觉检查产品缺陷；
- 医疗影像辅助医生诊断。

## 7 动手练习

1. 从你每天使用的 App 中找出 3 个机器学习应用，判断它们属于监督学习还是无监督学习；
2. 到 Kaggle 浏览一个带标签的公开数据集，指出其中的特征和标签分别是什么；
3. 思考：预测股票涨跌是回归还是分类？为什么两者都可能成立？
