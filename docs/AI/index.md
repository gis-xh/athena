# AI 与算法

> 从机器学习入门到深度学习与大模型应用：本模块是仓库内容最丰富的部分，按“概念 → 框架 → 应用”组织。

## 适合谁 / 前置要求

- 想系统学习 AI 的开发者与学生；
- 零基础建议从[机器学习课程](../AI/courses/machine-learning/index.md)开始；
- 编程基础可同步学习 [NumPy 入门](../AI/data-analysis/numpy/index.md)。

## 学习路径

1. **机器学习**（入门）：[机器学习课程](../AI/courses/machine-learning/index.md)，建立监督/无监督学习概念；
2. **数据分析**（入门）：[NumPy](../AI/data-analysis/numpy/index.md)、[Matplotlib](../AI/data-analysis/matplotlib/01-intro.md)、[Excel 处理](../AI/data-analysis/python-excel/01-excel.md)、[爬虫](../AI/data-analysis/spider/01-spider.md)；
3. **深度学习**（进阶）：[PyTorch](../AI/deep-learning/pytorch/index.md)、[Keras](../AI/deep-learning/keras/index.md)、[CS230 课程](../AI/courses/cs230-2018/index.md)；
4. **大语言模型**（入门 → 进阶）：[LLM 系列](../AI/llm/index.md)，从预训练、Transformer 到微调；
5. **AI 应用**（进阶）：[AI Agents](../AI/agents/index.md)、[Deeplearning.AI 课程](../AI/courses/deeplearning-ai/index.md)、[AI 课程索引](../AI/courses/index.md)。

## 能力目标

学完本模块你能：读懂机器学习/深度学习基础概念，用 NumPy 处理数据，用 Keras/PyTorch 训练简单模型，理解大模型原理并会调用与微调。

## 配套练习 / 项目

- 完成 CS230 作业 1（逻辑回归）并达到 70%+ 测试准确率；
- 用 Keras 在 MNIST 上复现[训练教程](../AI/deep-learning/keras/02-training/01-mnist.md)；
- 用 LangChain 搭建一个基于本地文档的问答 Demo（见 [LLM 07](../AI/llm/07-langchain.md)）。
