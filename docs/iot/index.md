# 物联网（IoT）

> 从传感器到云端：IoTDB 时序数据库、边缘计算与 OrangePi 开发板实践。

## 适合谁 / 前置要求

- 对硬件开发板与时序数据感兴趣的开发者；
- 建议先掌握 Python 基础与 Linux 基本命令。

## 学习路径

1. [物联网学习](iot-learning.md)（入门）：IoTDB 快速上手与核心概念；
2. [OrangePi 设备使用](orangepi.md)（入门）：开发板配置与硬件实践；
3. [边缘计算](edge-computing.md)（进阶）：边缘部署与模型推理。

## 能力目标

学完后你能完成传感器数据的采集、时序数据库存储与简单可视化，并在开发板上跑通一个边缘计算案例。

## 配套练习 / 项目

- 用 Python 向 IoTDB 写入一组模拟传感器数据并查询；
- 在 OrangePi 上部署一个温度采集脚本并定时上报；
- 尝试把数据接入[前端 ECharts](../frontend/vue/echarts-charts.md) 做实时曲线。
