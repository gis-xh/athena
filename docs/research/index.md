# 学术研究

> 从读论文到写论文：文献管理、论文笔记方法、LaTeX 排版、文献分析与科研工具链。

## 适合谁 / 前置要求

- 研究生或需要系统阅读英文文献的科研人员；
- 建议先掌握基础的文件管理与 Git 使用（见[工程化实践](../engineering/index.md)）。

## 学习路径

1. [论文研读准备](paper-reading-prepare.md)（进阶）：Typora + Git、Zotero、Google 学术、LetPub、Connected Papers；
2. [论文笔记与写作方法](paper-note-method.md)（进阶）：综述/实验论文的记录区别与写作步骤；
3. [论文数据分析流程](paper-analysis-workflow.md)（进阶）：WOS 检索 → 清洗 → 翻译 → 词频/聚类 → 可视化；
4. [CiteSpace 文献分析](citespace.md)（进阶）、[LaTeX 文档撰写](latex-writing.md)（进阶）、[ChatGPT 学术优化](chatgpt-academic.md)（进阶）、[腾讯云翻译 API](tencent-translate-api.md)（进阶）。

## 能力目标

学完后你能建立自己的文献库与论文笔记体系，独立完成一篇论文的文献综述数据分析和 LaTeX 排版。

## 配套练习 / 项目

- 用 Zotero 建立 30 篇文献的条目库并做一次引用；
- 用本仓库的流程完成一个小型文献计量分析（10-20 篇）；
- 用 LaTeX 模板排版一篇短文并编译为 PDF。
