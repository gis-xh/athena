## 使用步骤

### 使用 WOS 检索论文

1. 使用公式检索，缩减文献检索范围
2. 善用关键词与主题
3. 将检索结果导出成 RIS 格式

### 在 CiteSpace 中分析

1. 创建 `input`、`output`、`project`、`data` 文件夹
2. 顶部工具栏 data → import 导入数据
3. 配置好参数即可开始运行
