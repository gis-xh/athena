# 论文笔记与写作方法

## 综述论文和实验论文的记录区别

1. **目的不同**：综述论文是对已有研究的综合和归纳，实验论文则介绍某一项实验的研究结果。记录综述论文笔记时，可以将每一篇相关文献的摘要记录下来，方便以后查阅和回顾；实验论文则重点记录实验方法和结果。
2. **内容不同**：综述论文通常包含很多文献的概述，应尽量记录每篇文献的核心内容，以便对整篇综述的理解和记忆；实验论文可以详细记录实验方法、数据分析等内容，以便以后参考。

总体而言，记录笔记是为了方便以后的回顾和查阅，应重点关注文献的核心内容，并清晰地记录下来。

## 综述论文阅读记录

### 主要概括点

1. 研究背景：对领域或问题的历史背景、现状以及未来发展前景进行介绍
2. 研究内容：对已有研究成果、方法和技术进行系统性概括与分类汇总，并分析已有研究中存在的问题和不足
3. 研究结论：总结研究内容，评价研究成果，提出未来研究展望

### 思维导图记录步骤

1. 预读综述论文，明确文章主题以及作者的研究方向和目的
2. 提炼文章架构，确定文章结构，识别主要章节和小节
3. 提取关键点，如目的、方法、结果和结论等
4. 绘制思维导图，可使用不同颜色和线条粗细区分不同信息
5. 整理笔记，绘制完成后整理文章概述，便于以后查看和回顾

## 论文写作基本步骤

1. 选择关注的具体方面：领域较宽泛时，先缩小关注范围（如 GEE 在农业、资源管理或灾害管理等领域的应用）
2. 进行深入研究：使用可靠来源，如同行评审期刊、政府报告、案例研究等
3. 组织信息：使用清晰、有逻辑的结构组织研究发现
4. 撰写清晰简洁的引言：概述主题并说明其重要性
5. 呈现发现与讨论：在正文中呈现研究发现并讨论其意义
6. 总结并给出建议：总结主要发现，为未来研究或行动提出建议
7. 校对与编辑：仔细校对语法、拼写和标点错误

始终记得引用来源并遵守学术诚信规范。
