# 前端学习（Frontend）

> 从 Vue 基础到 Web3D 可视化：本模块覆盖现代前端开发、GIS 可视化和数据大屏常用技术栈。

## 适合谁 / 前置要求

- 需要搭建网页界面或数据可视化应用的开发者；
- 前置：HTML/CSS/JavaScript 基础，环境配置见[开发工具](../setup/dev/index.md)。

## 学习路径

1. [Vue 学习](vue/index.md)（入门 → 进阶）：基础语法、Vue2 转 Vue3、ECharts、Element Plus；
2. [Vue + TypeScript 项目初始化](vue-implementation.md)（进阶）：Vite + Vue + Tailwind 工程实践；
3. [UI 框架](01-ui-frameworks.md)（入门）：组件库与 CSS 框架选型；
4. [React 实现](react-implementation.md)（进阶）：React 项目实践；
5. [Web3D](03-web3d.md)（进阶）、[Cesium GIS](04-cesium.md)（进阶）、[GeoServer](05-geoserver.md)（进阶）。

## 能力目标

学完后你能独立初始化一个 Vue3 + Vite 项目，完成页面布局、数据可视化图表和地图展示，并理解组件化开发思路。

## 配套练习 / 项目

- 用 Vue3 + ECharts 实现一个带筛选条件的仪表盘；
- 用 Vue + TypeScript 模板初始化一个真实页面并部署；
- 在 Cesium 中加载一份本地 GeoJSON 并添加点击交互。
