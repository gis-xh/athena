# Linux 目录结构

> 本页是 Linux 学习的第一课：理解“一切皆文件”的树形目录结构，知道常用目录各自放什么，是后续命令学习的地基。

## 学习目标

- 理解 Linux 使用树形目录组织文件，根目录为 `/`；
- 记住 `/bin`、`/etc`、`/home`、`/var`、`/tmp` 等核心目录的用途；
- 掌握 `pwd`、`cd`、`ls` 三个最基础的命令。

## 前置要求

- 有一个可操作的 Linux 环境（虚拟机、WSL 或云服务器均可）；
- 参考[虚拟机操作](../vm-operations.md)完成环境准备。

## 1 树形结构

Linux 的目录从根目录 `/` 开始，像一棵倒挂的树：

```text
/
├── bin
├── etc
├── home
│   └── user
├── root
├── tmp
├── usr
└── var
```

在 Linux 中，“一切皆文件”：设备、进程信息等也以文件形式暴露在目录中。

## 2 常用目录一览

| 目录 | 作用 | 备注 |
| --- | --- | --- |
| `/` | 根目录，所有路径的起点 | 不要随意删除其中内容 |
| `/bin` | 系统基本命令 | 如 `ls`、`cp` |
| `/etc` | 系统与软件配置文件 | 如网络、用户配置 |
| `/home` | 普通用户的主目录 | 每个用户一个子目录 |
| `/root` | root 用户的主目录 | |
| `/tmp` | 临时文件 | 重启后可能被清理 |
| `/usr` | 系统软件与库 | 类似 Windows 的 Program Files |
| `/var` | 经常变化的数据 | 日志、缓存、邮件等 |
| `/dev` | 设备文件 | 如磁盘、终端 |
| `/proc` | 运行时内核信息 | 虚拟文件系统 |

## 3 三个入门命令

```bash
pwd          # 打印当前所在目录
cd /home     # 切换到 /home
ls -la       # 列出当前目录内容（含隐藏文件）
```

常用技巧：

- `cd ..` 返回上一级目录；
- `cd ~` 回到当前用户主目录；
- `ls -lh` 以人类可读的方式显示文件大小。

## 4 常见坑

1. Windows 用户容易把路径分隔符写成 `\`，Linux 统一使用 `/`；
2. 不要在 `/tmp` 存放重要文件，系统清理时可能丢失；
3. 不要用 `rm -rf /` 或类似命令，根目录内容无法恢复；
4. 修改 `/etc` 下的文件前先备份。

## 5 动手练习

1. 用 `pwd` 查看当前目录，再用 `cd /` 和 `ls -la` 查看根目录内容；
2. 找出 `/etc`、`/var/log`、`/home` 下各自有什么类型的文件；
3. 在 `/tmp` 下创建一个测试目录 `test-dir`，用 `rmdir` 删除它；
4. 用 `man ls` 查看 `ls` 的帮助，找到按大小排序的参数。
