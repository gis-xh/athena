# 新手快速入门指南

面向所有新手的电脑使用与学习起步指南。浏览器插件与常用网站见[浏览器与常用网站](browser-setup.md)，办公 / 开发软件清单见[Windows 常用工具](windows-tools.md)。

## 起步实践

1. 依次安装[Windows 常用工具](windows-tools.md)中列出的办公类软件
2. 注册团队协作平台并加入所在组织
3. 使用 WPS 灵犀等 AI 工具撰写文档 / PPT
4. 使用 XMind 等思维导图软件梳理学习笔记 / 学习心得
5. 使用 Zotero 等工具阅读和管理领域内的优质资料（论文、教程等）

## 编程入门

1. 依次安装[Windows 常用工具](windows-tools.md)中列出的开发类软件
2. 掌握 Git 基本使用方法，实现将本地代码上传至 Git / GitHub，可参考[Git 工作流](../../engineering/git-workflow.md)
3. 掌握 Conda 基本使用方法，实现镜像创建和激活操作，可参考[Python Conda 配置](../dev/python-conda-setup.md)
4. 借助 Trae 等 AI 编辑器初步掌握 Python 基本语法
