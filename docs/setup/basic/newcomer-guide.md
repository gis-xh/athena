# 新手快速入门指南

## 一、必备浏览器插件

1. **AdGuard**：广告过滤插件，过滤浏览器广告。必装，否则搜索时极易跳转广告。
2. **沉浸式翻译**：保留原文、不影响原文显示的翻译插件。
3. **EasyScholar**：显示论文级别的插件，<https://www.easyscholar.cc/>

!!! note
安装软件时，请先安装无广告插件后再搜索，防止搜索时被首位广告误导。以下所有软件均可在官网直接免费下载 Windows 版本。

## 二、必备办公类软件

1. **WPS**：AI 写作辅助
2. **向日葵 / ToDesk**：远程桌面
3. **腾讯会议**：视频会议
4. **钉钉 / 企业微信**：团队协作办公
5. **XMind 等**：思维导图
6. **Zotero**：论文阅读器
7. **Chatbox / Cherry Studio**：主流 AI 桌面端软件
8. **QGIS**：GIS 制图

## 三、必备开发类软件

1. **Git**：代码管理
2. **Miniforge**：管理 Python 镜像环境，Miniforge < Miniconda < Anaconda，<https://conda-forge.org/download/>
3. **Docker Desktop**：部分安装环境复杂的软件可直接使用 Docker 镜像（如 GeoServer）
4. **Nvm**：管理 Node 版本，前端开发使用，<https://nvm.uihtm.com/>
5. **Trae / VS Code**：AI 开发编辑器

## 四、必备网站

!!! note
以下网站需要借助网络工具才能访问。

1. 代码仓库：<https://github.com/>
2. 主流大模型分享站：<https://huggingface.co/>
3. 谷歌学术：<https://scholar.google.com/>
4. 遥感云平台：<https://earthengine.google.com/platform/>
5. AI 网站设计：<https://huggingface.co/spaces/enzostvs/deepsite>
6. Docker 镜像站：<https://hub.docker.com/>

## 五、起步实践

1. 依次安装所有办公类软件
2. 注册团队协作平台并加入所在组织
3. 使用 WPS 灵犀等 AI 工具撰写文档 / PPT
4. 使用 XMind 等思维导图软件梳理学习笔记 / 学习心得
5. 使用 Zotero 等工具阅读和管理领域内的优质资料（论文、教程等）

## 六、编程入门

1. 依次安装所有开发类软件
2. 掌握 Git 基本使用方法，实现将本地代码上传至 Git / GitHub
3. 掌握 Conda 基本使用方法，实现镜像创建和激活操作
4. 借助 Trae AI 辅助初步掌握 Python 基本语法
