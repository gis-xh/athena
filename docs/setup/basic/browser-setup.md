# 浏览器与常用网站

## 必备浏览器插件

1. **AdGuard**：广告过滤插件，过滤浏览器广告。必装，否则搜索时极易跳转广告。
2. **沉浸式翻译**：保留原文、不影响原文显示的翻译插件。
3. **EasyScholar**：显示论文级别的插件，<https://www.easyscholar.cc/>

!!! note
安装软件时，请先安装无广告插件后再搜索，防止搜索时被首位广告误导。
