三、必备开发类软件安装篇
1、Git：代码管理
2、Miniforge：管理Python镜像，Miniforge\<Miniconda\<Ananconda，<https://conda-forge.org/download/>
3、Docker Desktop：部分安装环境复杂的软件可直接使用Docker镜像（如GeoServer）
4、Nvm：管理node版本，前端开发使用，<https://nvm.uihtm.com/>
5、Trae/VS Code：AI 开发编辑器
