# 环境配置

> 把电脑从“能用”配置到“好用”：浏览器、终端、开发语言和容器环境一站搞定，是所有学习模块的第一步。

## 适合谁 / 前置要求

- 完全零基础的新手，从[新手快速入门](basic/newcomer-guide.md)开始；
- 需要统一开发环境的老手，可直接按需查阅对应章节。

## 学习路径

1. [基础应用](basic/index.md)（入门）：浏览器、常用软件、终端配置与 Windows 问题排查；
2. [开发工具](dev/index.md)（入门）：Node.js、Conda、uv 等语言环境；
3. [容器环境](deploy/index.md)（入门）：Docker 与容器化开发环境。

## 能力目标

学完本模块后，你应该能独立完成一台新电脑的开发环境搭建，并知道常见安装问题的排查思路。

## 配套练习 / 项目

- 用一台新电脑（或虚拟机）按顺序完整走一遍[新手快速入门](basic/newcomer-guide.md)；
- 分别用 Conda 和 uv 创建同一个 Python 虚拟环境，对比两种方式；
- 在 Docker 中跑通一个官方示例镜像（如 `hello-world`）。

## 参考资源

- 各页面内附官方文档链接；
- 遇到 Windows 特有问题时优先查看[问题汇总](basic/windows-troubleshooting.md)。
