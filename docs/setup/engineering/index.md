# 工程化实践

> 从“能写代码”到“能协作”：版本控制、分支管理、代码规范与团队协作，是进入任何团队项目前的必修课。

## 适合谁 / 前置要求

- 已完成[环境配置](../index.md)；
- 建议先掌握基本命令行操作。

## 学习路径

1. [Git 工作流](git-workflow.md)（入门）：安装、初始化、提交、分支与远程协作；
2. [WOS 论文分析开发日志](wos-paper-analysis-dev-log.md)（进阶）：自动化办公项目的实战记录；
3. 代码规范与团队协作（规划中，暂未开放）。

## 能力目标

学完后你能独立完成“本地开发 → 提交 → 推送 → 发起合并请求”的完整流程，并看懂团队常用的 Git 协作约定。

## 配套练习 / 项目

- 在本地仓库完成 10 次以上有意义的提交，包含分支合并；
- 模拟多人协作：两个分支同时修改同一文件，手动解决一次冲突；
- 配置 Git 别名，把高频命令缩短到 1-2 个字母。
