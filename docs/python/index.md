# 后端开发

> 用 Python 构建 Web 应用与桌面工具：Django 全栈、FastAPI 微服务、PyQt 桌面程序与打包发布。

## 适合谁 / 前置要求

- 已掌握 Python 基础语法（可先学习[数据分析中的 NumPy](../AI/data-analysis/numpy/index.md)练手）；
- 环境配置见[Python uv](../setup/dev/python-uv-setup.md) 或 [Python Conda](../setup/dev/python-conda-setup.md)。

## 学习路径

1. [Django 入门](01-django/index.md)（入门 → 进阶）：环境配置、官方教程、两个完整项目；
2. [FastAPI 微服务](03-fastapi/index.md)（入门）：路由、请求体、自动文档；
3. [Python GUI 开发](02-gui/index.md)（入门）：PyQt 桌面应用；
4. [PyInstaller 打包](pyinstaller-setup.md)（入门）：把 Python 程序发布为可执行文件。

## 能力目标

学完后你能独立开发并部署一个 Django 网站或 FastAPI 接口服务，也能把小型工具打包给非技术用户使用。

## 配套练习 / 项目

- 完成 Django 教程中的投票应用并扩展一个自定义模型；
- 用 FastAPI 写一个待办事项接口，并用 Swagger 文档调试；
- 用 PyQt 做一个文件批量重命名小工具，再用 PyInstaller 打包。

## 参考资源

- [Django 官方文档](https://docs.djangoproject.com/zh-hans/)；
- [FastAPI 官方文档](https://fastapi.tiangolo.com/zh/)。
