# 3D 建模

> 用 Blender 入门三维建模：从软件安装到基础建模操作，为 Web3D、GIS 可视化等方向打基础。

## 适合谁 / 前置要求

- 零基础即可开始，无需美术功底；
- 需要一台能运行 Blender 的电脑。

## 学习路径

1. [Blender 软件](blender.md)（入门）：安装、界面与基础操作。

## 能力目标

学完后你能独立完成简单模型的创建、材质与渲染导出。

## 配套练习 / 项目

- 用 Blender 建模一个低多边形小房子并渲染输出；
- 把模型导出为 glTF/OBJ，尝试在[前端 Web3D](../frontend/03-web3d.md) 页面中加载。
